# 規劃模式範例

以下用真實案例，示範如何在 Claude Code 中有效運用規劃模式（Planning Mode）。

## 範例 1：建立 REST API

### 不使用規劃模式

```
User: 建立一個部落格的 REST API

Claude: 我來建立這個 API…
[立刻開始寫程式，可能漏掉需求]
```

### 使用規劃模式

```
User: /plan 建立一個部落格的 REST API

Claude: 讓我為這個部落格 API 建立一份完整的計畫。

## 範例 3：前端重構

```

   - 複雜（多個生命週期、refs）：約 8 個元件
3. 找出需要更新的第三方函式庫
4. 建立元件相依關係圖
5. 規劃遷移順序（先從葉節點開始）

## 重點整理

### 規劃模式的優點

1. **清晰**：開始前就有明確的路線圖
2. **預估**：提供時間與工作量估算
3. **風險評估**：及早找出潛在問題
4. **優先順序**：任務排序合理
5. **核准**：執行前先審查並核准
6. **修改**：可依回饋調整計畫

### 何時該用規劃模式

✅ **一律建議使用**：
- 需要多天完成的專案
- 團隊協作
- 關鍵系統變更
- 學習新概念
- 複雜重構

❌ **不建議使用**：
- 修 bug
- 小幅調整
- 簡單查詢
- 快速實驗

### 最佳實踐

1. 核准前**仔細審查計畫**
2. 發現問題就**修改計畫**
3. **拆解**複雜任務
4. **估算符合實際**的時程
5. **納入回滾**策略
6. **加入成功**標準
7. 每個階段都**規劃測試**
