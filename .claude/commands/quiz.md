# Quiz Generator（章節小考）

依教學章節內容自動出考題，幫助學員（或你自己）檢查有沒有真的讀懂。

## 找章節

1. 參數 `$1`：可以是 `03`、`03-slash-commands`、或完整路徑。
2. 用 Glob 找 `docs/$1*` 或 `docs/*$1*`，定位到該章資料夾。
3. 找不到就列出 `docs/` 下所有章節，請使用者重選。
4. 讀該章 `README.md`（必讀）；若有 `examples/` 也快速掃一下檔名。

## 出題規則

從章節內容中**只出有依據的題**，不准腦補不存在的內容。

題型混合：

- 2 題單選（4 個選項，只有一個正解）
- 2 題簡答（一句話可答完）
- 1 題情境題（給一個小情境，問「這時你會怎麼做、為什麼」，無標準答案，但要附「參考思路」）

每題格式：

```markdown
### Q<n>. <題目>

- A. ...
- B. ...
- C. ...
- D. ...

<details>
<summary>參考答案</summary>

**答案**：B

**為什麼**：<2–3 句解釋，引用章節中具體段落或概念>
</details>
```

簡答題用：

```markdown
### Q<n>. <題目>

<details>
<summary>參考答案</summary>

<答案 + 解釋>
</details>
```

## 落檔

寫到 `Projects/quiz/<章節編號>.md`：

```markdown
# <章節編號> 小考

> 來源：docs/<章節資料夾>/README.md
> 共 5 題，建議花 10 分鐘作答後再展開答案。

<五題>

---

## 我的得分
- [ ] 4–5 對：可以進下一章
- [ ] 2–3 對：建議重讀重點段落
- [ ] 0–1 對：建議從頭再讀一次
```

完成後告訴使用者：題目檔案路徑、五題各考哪個重點（一句話）。
