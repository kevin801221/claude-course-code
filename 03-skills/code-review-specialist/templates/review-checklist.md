# 程式碼審查檢查清單

## 安全性檢查清單
- [ ] 沒有寫死的憑證或機密資訊
- [ ] 所有使用者輸入都有做輸入驗證
- [ ] 防範 SQL 注入（使用參數化查詢）
- [ ] 會變更狀態的操作有 CSRF 防護
- [ ] 有做適當的跳脫處理來防範 XSS
- [ ] 受保護的端點有做身分驗證檢查
- [ ] 資源有做授權檢查
- [ ] 密碼使用安全的雜湊方式（bcrypt、argon2）
- [ ] 日誌中沒有敏感資料
- [ ] 強制使用 HTTPS

## 效能檢查清單
- [ ] 沒有 N+1 查詢
- [ ] 適當使用索引
- [ ] 在有益處的地方實作了快取
- [ ] 主執行緒上沒有阻塞操作
- [ ] Async/await 使用正確
- [ ] 大型資料集有做分頁
- [ ] 資料庫連線有做連線池管理
- [ ] 正規表達式已最佳化
- [ ] 沒有不必要的物件建立
- [ ] 已防範記憶體洩漏

## 品質檢查清單
- [ ] 函式少於 50 行
- [ ] 變數命名清楚
- [ ] 沒有重複程式碼
- [ ] 有適當的錯誤處理
- [ ] 註解解釋的是「為什麼」，不是「做什麼」
- [ ] 正式環境中沒有 console.log
- [ ] 有做型別檢查（TypeScript／JSDoc）
- [ ] 遵循 SOLID 原則
- [ ] 設計模式運用正確
- [ ] 程式碼具自我說明性

## 測試檢查清單
- [ ] 已撰寫單元測試
- [ ] 涵蓋邊界情況
- [ ] 已測試錯誤情境
- [ ] 有整合測試
- [ ] 涵蓋率 > 80%
- [ ] 沒有不穩定（flaky）的測試
- [ ] 外部相依項目已做 mock
- [ ] 測試名稱清楚易懂
