# 程式碼審查技能

這個技能（Skills）提供全方位的程式碼審查能力，聚焦於：

1. **安全性分析**
   - 身分驗證／授權問題
   - 資料外洩風險
   - 注入攻擊漏洞
   - 密碼學弱點
   - 敏感資料寫入日誌

2. **效能審查**
   - 演算法效率（Big O 分析）
   - 記憶體最佳化
   - 資料庫查詢最佳化
   - 快取機會
   - 並行問題

3. **程式碼品質**
   - SOLID 原則
   - 設計模式
   - 命名慣例
   - 文件
   - 測試涵蓋率

4. **可維護性**
   - 程式碼可讀性
   - 函式長度（應少於 50 行）
   - 循環複雜度
   - 相依套件管理
   - 型別安全

## 參考檔案

這個技能包含一些輔助檔案，執行審查時應該讀取這些檔案：

- **`templates/review-checklist.md`** — 涵蓋安全性、效能、品質、測試的結構化檢查清單。讀取這個檔案，並用它作為指引，確保審查過程沒有遺漏任何類別。
- **`templates/finding-template.md`** — 用來記錄個別發現的標準範本，包含嚴重程度、位置、程式碼範例與影響分析。讀取這個檔案，回報問題時採用它的格式。
- **`scripts/analyze-metrics.py`** — Python 腳本，計算程式碼指標（函式數量、類別數量、平均行長、複雜度分數）。針對正在審查的檔案執行這個腳本，以取得量化資料。
- **`scripts/compare-complexity.py`** — Python 腳本，比較同一檔案前後兩個版本之間的循環複雜度與認知複雜度。審查重構變更時，用這個腳本比較前後版本。

## 審查範本

針對審查的每一段程式碼，請提供：

### 摘要
- 整體品質評分（1-5）
- 主要發現數量
- 建議優先處理的區域

### 重大問題（如果有）
- **問題**：清楚的描述
- **位置**：檔案與行號
- **影響**：為什麼這件事重要
- **嚴重程度**：Critical／High／Medium
- **修正方式**：程式碼範例

### 依類別分類的發現

#### 安全性（如果找到問題）
列出安全性漏洞，並附上範例

#### 效能（如果找到問題）
列出效能問題，並附上複雜度分析

#### 品質（如果找到問題）
列出程式碼品質問題，並附上重構建議

#### 可維護性（如果找到問題）
列出可維護性問題，並附上改善建議
