# 審查報告的證據格式

對應講義 Part 19；兩份模板原樣保留自 howto 的 code-review-specialist。

- [review-checklist.md](review-checklist.md)：檢查面向的提示。
- [finding-template.md](finding-template.md)：記錄一個發現的欄位。

使用方式：先跑實際功能與測試，再依檢查清單追查；找到缺陷才建立 finding。不要為了填滿模板而捏造漏洞、效能數字或商業影響。來源模板中的日期、範例、估算都是示意，請換成這次實際證據。

驗收：每個問題有位置、觸發條件、影響與修正方向；另一位同學可以重現。
