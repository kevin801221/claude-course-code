# 先寫上下文，再交辦

對應講義 Part 09 Context Engineering、Part 19 可驗收的成果。
[PRP.md](PRP.md) 保留來源範本的目標、必要上下文、整合點、小步實作及驗證迴圈，去掉長篇示意程式與尚未存在的工具命令。

1. 複製成自己專案的 `task.md`，填入一個 20 分鐘可完成的小需求。
2. 每個接受標準都應有操作或測試證據。
3. 啟動 Claude 後說：「先讀 CLAUDE.md 與 task.md，列出必要資訊與缺口，再按任務範圍實作。」
4. 換一個新 session，僅提供這兩份文件，看它是否仍能理解完成條件。

驗收：另一位同學不用聽口頭補充，就能找到程式、執行檢查並判斷是否完成。
