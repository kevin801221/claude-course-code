# 研究筆記範本(research-synthesizer 要填的格式)

> synthesizer 讀完三份分析後,照這個骨架填出 `research-note.md`。
> 一頁為限。重點是「攤開三鏡頭的一致與矛盾」,不是寫長。

---

```markdown
# <TICKER> 研究筆記 — <YYYY-MM-DD>

> 本文為 Claude Code 教學範例,非投資建議。三鏡頭數字均含抓取日期,可能有時間差。

## 一句話摘要
<把三鏡頭壓成一句:目前市場用什麼故事定價、最大的多空拉扯在哪>

## 三鏡頭重點
| 鏡頭 | 一句話 | 偏向 |
|---|---|---|
| 基本面 | <估值貴/便宜、賺不賺、成長有沒有> | 偏多 / 中性 / 偏空 |
| 技術面 | <趨勢、動能、位置> | 偏多 / 中性 / 偏空 |
| 新聞情緒 | <近期敘事與關鍵事件> | 偏多 / 中性 / 偏空 |

## 三鏡頭一致的訊號
- <三條鏡頭都指向同方向的點 —— 共識,信心較高>

## 彼此矛盾的訊號 ⭐(這欄是這份筆記的核心價值)
- <例:基本面估值便宜 vs 新聞一片利空 → 是價值陷阱還是落難轉機?>
- <把矛盾攤開,不要喬成一致>

## 多空總表
| 偏多的理由 | 偏空的理由 |
|---|---|
| <fact / 解讀> | <fact / 解讀> |

## 還沒回答的問題(待追蹤)
- <下次研究要補的資料、要等的事件(財報日、法說、判決)>

## 怎麼用這份筆記(取代買賣建議)
- 若你重視 <X>:偏多的理由是 …
- 若你擔心 <Y>:偏空的理由是 …
- 結論留給你自己 —— 這份筆記只負責把事實與論點攤平。

> 再次提醒:教學範例,非投資建議。
```
