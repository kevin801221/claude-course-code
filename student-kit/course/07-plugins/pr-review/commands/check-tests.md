# 測試涵蓋率檢查

分析測試涵蓋率與品質：

1. 檢查測試涵蓋率百分比
2. 找出未經測試的程式碼路徑
3. 檢視測試品質
4. 建議缺漏的測試案例
5. 確認邊界案例都已涵蓋
