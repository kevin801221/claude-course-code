# 建立 MCP 伺服器 PRP (Create MCP Server PRP)

建立一個全面的產品需求提示 (PRP)，用於構建具備身分驗證、資料庫整合和 Cloudflare Workers 部署功能的模型上下文協定 (MCP) 伺服器。

在開始之前，請確保您閱讀了這些關鍵檔案以了解 PRP 的目標：
PRPs/README.md
PRPs/templates/prp_mcp_base.md (此基礎 PRP 已根據專案結構部分填寫，但請針對使用者特定的 MCP 伺服器用例完成它)

## 使用者的 MCP 用例： $ARGUMENTS

## 目的

生成專為 MCP 伺服器開發設計的豐富上下文 PRP，使用本程式碼庫中經過驗證的模式。本程式碼庫是 MCP 伺服器設定的支架，使用者可以在此基礎上進行構建，包括 GitHub OAuth 和生產就緒的 Cloudflare Workers 部署。

現有的工具可能都不會被重複使用，應針對使用者的用例專門量身定制工具。

## 執行流程

1. **研究與上下文收集**
   - 建立清晰的待辦事項並啟動子代理人，在程式碼庫中搜尋類似的功能/模式。深入思考並規劃您的方法。
   - 收集有關 MCP 工具、資源和身分驗證流程的相關文件。
   - 研究現有的工具模式，以了解如何構建使用者指定的用例。
   - 研究程式碼庫中現有的整合模式。

2. **生成全面的 PRP**
   - 使用專門的 `PRPs/templates/prp_mcp_base.md` 範本作為基礎。
   - 根據特定的伺服器需求和功能自訂範本。
   - 包含來自程式碼庫模式和 `ai_docs` 的所有必要上下文。
   - 為 MCP 伺服器開發新增特定的驗證迴圈。
   - 包含資料庫整合模式和安全性考量。

3. **使用 AI 文件進行增強**
   - 使用者可能在 `PRPs/ai_docs/` 目錄中新增了文件，您應該閱讀這些文件。
   - 如果 `PRPs/ai_docs/` 目錄中有文件，請審查它們並在構建 PRP 時將其納入上下文。

## 實作細節

### MCP 伺服器的 PRP 結構

生成的 PRP 使用專門的範本 `PRPs/templates/prp_mcp_base.md` 並包含：

- **目標**：清晰描述要構建的具備身分驗證和資料庫整合的 MCP 伺服器。
- **上下文**：所有必要的文件，包括 `PRPs/ai_docs/` 參考資料和現有的程式碼庫模式。
- **實作藍圖**：遵循 Cloudflare Workers 模式的逐步 TypeScript 任務。
- **驗證迴圈**：從編譯到生產部署的全方位 MCP 特定測試。
- **安全性考量**：GitHub OAuth 流程、資料庫存取模式和 SQL 注入防護。

### 關鍵特點

- **豐富上下文**：包含使用此經過驗證的程式碼庫相對路徑的所有模式和參考。
- **驗證驅動**：從語法到生產部署的多層次驗證。
- **安全性優先**：內建身分驗證和授權模式。
- **生產就緒**：Cloudflare Workers 部署與監控。

### 研究領域

1. **MCP 協定模式**
   - 工具註冊與驗證。
   - 資源服務與快取。
   - 錯誤處理與日誌記錄。
   - 用戶端通訊模式。

2. **身分驗證整合**
   - GitHub OAuth 實作。
   - 使用者權限系統。
   - Token 管理與驗證。
   - 對話 (Session) 處理模式。

## 輸出

在 `PRPs/` 目錄中建立一個全面的 PRP 檔案，包含：

- 所有必要的上下文和程式碼模式。
- 逐步的實作任務。
- 用於 MCP 伺服器開發的驗證迴圈。

## 驗證

該命令確保：

- 所有參考的程式碼模式都存在於程式碼庫中。
- 文件連結有效且可存取。
- 實作任務具體且可執行。
- 驗證迴圈全面且可由 Claude Code 執行 (重要)。

## 與現有模式整合

- 使用來自 `PRPs/templates/prp_mcp_base.md` 的專門 MCP 範本。
- 遵循建立的目錄結構和命名慣例。
- 與現有的驗證模式和工具整合。
- 利用 `src/` 中目前 MCP 伺服器實作中經過驗證的模式。
