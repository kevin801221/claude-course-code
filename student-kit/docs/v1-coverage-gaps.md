v1有119個檔案，但來源清單49項中只有26份原樣、12份改寫，另11項只是導讀連結。很多檔案是新寫說明，並不等於收錄了五庫的大量實戰。上一次驗收著重能執行與連結，沒有檢查足夠的內容覆蓋，這是選材範圍的問題。

| 十模組只挑極少範本 | course/01–10全部來源模組 |
| 只3個講義小例 | 九個核心Projects及GitNexus/Plugin工具包 |

| 只有7篇導讀 | 39篇中文完整核心文件、訪談選讀、英文實際工作流 |
| Part15沒真正對應內容 | 專門平台操作導讀，清楚標無本機完整程式 |

保留v1為入門練習；v2的濃縮集中在清楚選課與去除重複媒體/環境/輸出，不再把完整程式碼縮成閱讀連結。指定附錄Notebook仍屬來源缺件，沒有另寫假原版。
