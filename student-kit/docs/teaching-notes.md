# 講師帶課建議

這是學生包，沒有附講師版完整 PDF；學生可用 [lecture-map.md](lecture-map.md) 對照投影片章節。

## 開課前十分鐘

確認所有人解壓時保留隱藏 `.claude/`。先跑 `npm test`、`npm run check`；沒登入 Claude 的同學也能先完成基礎程式與協定練習。針對 Windows 預先選擇 WSL，避免現場混用 Python 命令。

## 建議帶課順序

1. 先以根專案示範「輸入 → 工具 → 檔案 → 測試回饋」，連到 Part 00 Harness。
2. 用 Lab 00～02 定義任務卡，建立規則、權限與 context 習慣。
3. 以 `list --pending` 為共同作業，先規劃，實作後讓另一組用相同情境驗收。
4. Lab 03～07 每次只加一種擴充；用「輸入/產出/失敗」比較 Skill、Agent、Hook、MCP。
5. Lab 08 用真實天氣資料示範分工交接，再用斷網說明不能編數字。
6. 進階班再帶 Lab 09～11；ML 先讀契約，Mods 先跑離線測試，不把安裝大型環境當教學主線。

## 作業評量

每項 0～2 分，共 10 分：需求可觀察、保留原行為、錯誤可重現、證據可回查、下一位能接手。不以開了幾個 agents、回覆長度、模型名稱或自行聲稱「完成」評分。

## 主動安排的失敗情境

- 壞 tasks.json：應保留原檔，不能靜默重建。
- 找不到 MCP 主題：應回傳空結果，不編課程。
- Hook 壞 JSON：應在 stderr 回報並退出，不把原始輸入全文曝光。
- 無天氣網路：停止產圖，保留原因。
- RAG 查無證據：重寫達上限後停止。

保留未驗證項目，讓同學看見「程式測試通過」「靜態結構正確」「真人完整流程可用」是不同層次的證據。
