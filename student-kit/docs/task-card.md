# 任務卡：先定義何謂完成

對應講義 Part 09、19。複製到 `.outputs/task.md` 並填入真實需求。

| 欄位 | 本次任務 |
|---|---|
| 使用者與情境 | 課堂同學在終端機管理練習進度 |
| 主要行動 | 例如只列出尚未完成的任務 |
| 可信資料 | 目前 src/、bin/、tests/，不臆測未存在的 API |
| 輸入與輸出 | CLI 參數、stdout JSON、stderr、退出碼、檔案格式 |
| 成功條件 | 正常、空集合、錯誤輸入皆有明確行為 |
| 停止條件 | 資料格式不確定、需要破壞既有任務、超出範圍 |
| 交付內容 | 程式碼、回歸測試、使用例與實測結果 |

範例需求：`list --pending` 只回傳 `done: false` 的任務；不改 tasks.json；原本 `list` 保持行為；未知旗標回傳 1。

請先討論未知旗標和已存在多餘參數的行為，再開始實作。這個需求是練習，出廠版本尚未支援。

驗收至少包含：兩筆任務完成其中一筆、全部完成、沒有任務、資料損壞；用臨時目錄執行以免污染個人資料。
