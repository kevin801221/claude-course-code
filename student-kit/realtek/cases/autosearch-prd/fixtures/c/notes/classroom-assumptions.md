# 溫度告警教案的兩項假設

這份教案使用合成溫度資料。在本次實驗中，競品說明、使用者意見與供應商建議也是為課堂編寫的情境。

- **EV-004　評估協議**。每秒取樣一筆。濾波後的數值連續三筆有效且均大於或等於 45 °C，第三筆觸發告警。孤立的尖峰視為干擾。
- **EV-006　輸入資料**。每列 CSV 有 `timestamp_s` 和 `temp_c`；溫度空值表示缺測。處理缺測時，重置濾波狀態與連續計數。

需求追溯工具會從 [evidence.json](../evidence.json) 指回這兩項假設。產品告警延遲上限要另外決定，可對照[使用者意見](user_notes.md)與[競品資料](competitor_alpha.md)。
