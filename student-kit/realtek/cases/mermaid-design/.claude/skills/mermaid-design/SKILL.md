# Mermaid Design

讓讀者先看到流程與文字。程式碼能解析，只是第一關；視覺品質以實際呈現尺寸下的渲染結果判斷。

## 預設風格

採產品設計風：柔和圓角、白底或符合文件的底色、低飽和填色、深色文字、適度留白、一致的關鍵路徑。使用者提供的風格與正式製圖規範優先。中文預設繁體，既有專有名詞保留。

## 工作方式

1. **保留意義。** 列出必要節點、條件、分支與回路，再調整文案與排版。不得為了整齊刪除例外路徑、改變先後順序，或把循環畫成終點。
2. **先選構圖。** 已知時使用實際容器寬度；未知時先以 760 CSS px 文件寬度檢查。短流程可 LR；長流程或多分支先試 TB。遇到細長圖、大空洞、交叉或縮小後難讀，實際比較另一方向。超出容器時優先分層或拆成總覽與細節，保留對應與連線意義。
3. **讓節點貼合內容。** 每節點一個動作或問題；通常一行，必要時兩行。完整保留條件與數字，把不影響判斷的解說移到圖外。避免為了對齊統一寬高、強制正方形、塞空白字元或逐字斷行。
4. **套用風格。** 從 [產品風格範例](assets/product-flow.mmd) 起步。讀 [排版與相容性](references/layout.md) 處理尺寸、決策形狀、長標籤或目標平台限制。
5. **渲染並看圖。** 使用目標平台；若無法直接渲染，可用下方助手。開啟 PNG，在目標尺寸下檢查全部文字、箭頭、分支、回路和留白。看到問題就修正並重繪；有明顯構圖問題時至少比較一個替代版。數值報告不能取代看圖。
6. **交付一致的成品。** 提供最終 Mermaid 原始碼與同版預覽；需要檔案時保留 `.mmd` 和 SVG/PNG。簡述實際驗證的渲染器、寬度與限制。沒有看過成品時，標示「尚未完成視覺驗證」，不宣稱保證好看。

## 視覺驗收

| 項目 | 產品風格的起點與調整依據 |
| --- | --- |
| 文字 | 原始字級約 16–18px；縮放至最終寬度後盡量不低於 14px。先改構圖，勿靠縮小字體塞圖。 |
| 節點 | 多數一般短文字節點呈扁長形，常約 2–4:1；這是觀察範圍，不是固定寬高。單字、決策菱形和特殊形狀另判。 |
| 內距與間距 | 可從 padding 10、nodeSpacing 28、rankSpacing 40 起試；各自控制不同空間，必須看渲染效果。 |
| 決策 | 產品圖可用圓角問題節點，搭配明確的條件邊標籤；正式流程圖要求菱形時保留菱形，優先縮短問題與減少換行。 |
| 層級 | 一個主色貫穿關鍵流程，其他節點中性；綠／紅只表達成功／拒絕等語意。分支有文字，不只靠顏色。 |

交付前修正：文字裁切、節點重疊、箭頭方向不明、分支缺漏及縮放後無法閱讀。留白過多、比例不均、主路徑難追則修改構圖；不要只換顏色。不要為通過比例數字而拉寬節點。

## 輸出格式

這是五個入口的設計核心：`mermaid-design` 負責構圖與 Mermaid 原始碼；指定 PNG 時使用 `mermaid-png`，指定 SVG 時使用 `mermaid-svg`，指定 PDF 時使用 `mermaid-pdf`，需要 PowerPoint 或同時輸出 PNG／SVG／PPTX 時使用 `mermaid-ppt`。四個匯出入口沿用本技能的視覺規範。

同一個任務的多張圖，可依指定順序匯入一份多頁 `.pptx`；不同任務分開。PowerPoint 的節點、文字、連線須是可獨立編輯的原生物件，不能以整圖圖片替代。長圖依語意群組拆頁並保留跨頁承接，不把文字硬縮進一頁。完整格式規範見 [輸出與驗收](references/export-skills.md)。

## 本機預覽助手

需 Node.js 與既有 Mermaid CLI `mmdc`，不自動安裝或更新套件：

```sh
node <skill-dir>/scripts/render.mjs diagram.mmd --out preview --width 760
```

產出 `preview.svg`、在指定顯示寬度下以 2× 像素密度截取的 `preview.png`、以及 `preview.metrics.json`。PNG 是 SVG 的實際瀏覽器渲染。報告提示有效字級、節點比例和重疊；它不能判定美感、完整語意、字型缺字或所有線條碰撞。打開 PNG 檢視。參數見 `--help`。

## 常見誤用

- **「解析成功就交付」** → 還要開啟實際圖檢查；只看原始碼無法發現空洞與縮放。
- **「間距變小就能縮節點」** → `nodeSpacing`／`rankSpacing` 管節點之間；檢查形狀、標籤換行與內距。
- **「所有判斷都塞兩行菱形」** → 先縮短問題；產品圖可採圓角條件節點，保留所有分支語意。
- **「本機好看，貼哪都一樣」** → 目標平台可能忽略設定或使用不同版本與字型；未在該平台驗證就明說。

## 自動格式選擇

啟用 prompt hook 時，依 hook 的已確認格式路由。若尚未選格式，先詢問 PNG、SVG、PPTX、PDF（可複選）或僅原始碼，等待答覆再匯出；已指定格式則不重問。hook 不會自行執行 skill，由 agent 載入相應入口。
