# 主管：團隊日報彙整 Prompt

> 主管端使用。由排程腳本把 `{{DATE}}`、`{{TEAM_REPORTS_DIR}}`、`{{REPO_DIR}}` 換成實際值後執行。
> `{{TEAM_REPORTS_DIR}}` 是所有成員日報匯集的地方，例如共用 Git repo 同步下來的資料夾，結構為 `<成員>/daily/YYYY-MM-DD.md`。
> 如果報告庫在 Notion，改用 Notion 連接器查詢當天所有類型為「日報」的頁面。

請彙整 {{DATE}} 全團隊的日報。

## 步驟

1. 列出 `{{TEAM_REPORTS_DIR}}` 底下每位成員的 `daily/{{DATE}}.md`。
2. 逐一讀取，記下哪些成員沒有交日報。
3. 寫成團隊日報，存成 `{{REPO_DIR}}/reports/team/daily-{{DATE}}.md`。

## 格式

```markdown
# 團隊日報 {{DATE}}

## 一句話總結
<今天團隊整體狀況>

## 需要主管介入
- <事項>（<成員>）〔來源：<成員>/daily/{{DATE}}.md〕

## 各專案狀態
### <專案名稱>
- <成員>：<今日進展>

## 風險與卡關
- <問題>（<成員>，持續 <天數> 天）

## 未提交
- <成員名單，全部提交就寫「無」>
```

## 規則

- 「需要主管介入」放最上面，沒有就寫「無」。
- 每一項標出是哪位成員、引用其日報檔名。
- 依專案而不是依人來整理狀態。
- 用繁體中文、精簡。
