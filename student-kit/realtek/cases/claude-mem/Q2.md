# Q2｜同一份工作紀錄，怎麼產出個人與主管要看的報表？

工程師想先看完成的回歸測試，PM 想先看卡住的決定，主管需要跨成員的摘要。這個練習用兩位虛構成員和兩天的報名系統紀錄，從同一個 SQLite 資料庫產出每日及每週報表。

## 先跑出一週的報表

在本頁所在目錄，用 Python 3.9 以上執行。這兩步可離線完成。

~~~sh
python3 classroom.py save
python3 classroom.py reports
~~~

1. 開啟 practice/reports/members/eng/daily/2026-11-17.md，從完成項目找到 TEST-12。對照[合成證據](fixtures/evidence.md)，確認測試實際量到什麼。
2. 開啟 practice/reports/members/pm/weekly/2026-W47.md。PM 的偏好把「待查」排在「決議」前；工程師週報則優先列「完成」。打開兩人的報告，確認每份個人摘要只列出該成員的紀錄。
3. 開啟 practice/reports/team/weekly/2026-W47.md。主管可以同時看到未決的取消通知、已定案的名額規則，以及工程師的測試結果。兩天的團隊日報在 practice/reports/team/daily/。比對[預期團隊週報](expected/team-weekly.md)。
4. 要一次驗收，執行 python3 selfcheck.py。應顯示可跨程序查回 4 筆紀錄，並產出 8 份報告。

## 要接上自己的 Claude Code

[講師的日報範本](upstream/prompts/daily-report.md)由 search 取日期索引，再用 timeline 和 get_observations 補證據。[個人週報](upstream/prompts/weekly-report.md)讀每日摘要，[主管週報](upstream/prompts/team-weekly.md)讀團隊共同報告目錄。先預覽即將交給模型的文字：

~~~sh
python3 upstream/scripts/mac/render_prompt.py upstream/prompts/daily-report.md AUTHOR=學員 DATE=2026-11-17 REPO_DIR=. REPORT_DESTINATION= NOTION_REPORT_DB= JIRA_ISSUE=
~~~

正式使用需登入 Claude Code，安裝並連好 claude-mem，在 /mcp 查實際的搜尋伺服器名稱。收到許可後，複製 upstream/config/report.env.example 為同目錄下的 report.env，填署名與允許的工具。在共享資料夾按成員存放報告，把 TEAM_REPORTS_DIR 指向該目錄。線上每日腳本會把工作記錄組成 Markdown，主管腳本從收齊的成員回報彙整。週期排程、共享目錄同步與團隊存取權需在實際工作環境設定。

~~~sh
bash upstream/scripts/mac/run-report.sh daily
bash upstream/scripts/mac/run-report.sh team-weekly
~~~

Windows 版本位於 upstream/scripts/windows/run-report.ps1。上面兩個 shell 命令會使用真實 Claude Code 帳號；離線教室腳本使用固定規則產報表，並保留來源 ID，讓大家先驗證資料流。
