# Lab 10：交出下一位能接手的成果

講義 Part 18～20、附錄 B。先完成根專案 `list --pending` 作業，再從 [進階專案配方](../../advanced/project-recipes/README.md) 選一題。

## 選一條路

- **ML 四代理**：讀四個原始 agent，先產出每階段 input/output/success/failure 契約；本堂不下載資料或訓練模型。
- **Agent Teams**：對照 API 契約與檔案分工，先設計兩個互不覆寫的子任務與整合驗收。
- **AgenticRAG**：執行離線流程範例，檢查直接命中、問題重寫與停止三種 trace；它是概念控制流程，不是真實向量檢索或 LLM 系統。

## 每組交付

1. 一份填妥的 [任務卡](../../docs/task-card.md)。
2. 成果檔案與最小重現命令。
3. 正常、失敗、未知三種情境的觀察與處理方式。
4. 一份 [交接卡](../../docs/handoff-template.md)，清楚標明未驗證範圍。

## 驗收

交換給另一組，讓對方照交接卡重現一個結果。流程有退出條件；沒有無上限的「繼續直到成功」。來源模板的示例數字不當作本次量測。

ML 真訓練、外部模型、Teams 互動都需要額外環境，請依配方準備。講義附錄的 notebook 未存在於指定五個來源，本包已明確標示缺件。
