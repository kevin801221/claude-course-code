# 執行基礎 PRP (Execute BASE PRP)

使用 PRP 檔案實作功能。

## PRP 檔案：$ARGUMENTS

## 執行流程 (Execution Process)

1. **載入 PRP (Load PRP)**
   - 讀取指定的 PRP 檔案
   - 理解所有上下文和需求
   - 遵循 PRP 中的所有說明，並在需要時擴展研究
   - 確保您擁有完整實作 PRP 所需的所有上下文
   - 根據需要進行更多的網頁搜尋和程式碼庫探索

2. **深度思考 (ULTRATHINK)**
   - 在執行計畫前深入思考。建立一個滿足所有需求的全面計畫。
   - 使用您的待辦事項 (Todos) 工具將複雜任務分解為更小、易於管理的步驟。
   - 使用 TodoWrite 工具建立並追蹤您的實作計畫。
   - 從現有程式碼中識別要遵循的實作模式。

3. **執行計畫 (Execute the plan)**
   - 執行 PRP
   - 實作所有程式碼

4. **驗證 (Validate)**
   - 執行每個驗證命令
   - 修復任何失敗
   - 重新執行直到全部通過

5. **完成 (Complete)**
   - 確保完成所有檢查表項目
   - 執行最終驗證套件
   - 報告完成狀態
   - 再次閱讀 PRP 以確保您已實作所有內容

6. **參考 PRP (Reference the PRP)**
   - 如果需要，您可以隨時再次參考 PRP

注意：如果驗證失敗，請使用 PRP 中的錯誤模式進行修復並重試。
