# 範本生成器 (Template Generator) —— 上下文工程元框架 (Meta-Framework)

此範本生成器可為任何技術領域建立完整的上下文工程範本包。它是一個元範本 (Meta-template)，可以為 Pydantic AI、Supabase、CrewAI 等框架生成專門的範本。

## 🚀 快速開始

```bash
# 1. 詳細定義您的範本需求
# 使用特定的技術和需求編輯 PRPs/INITIAL.md

# 2. 生成全面的範本 PRP
/generate-template-prp PRPs/INITIAL.md

# 3. 執行 PRP 以建立完整的範本包
/execute-template-prp PRPs/template-{技術名稱}.md
```

## 📚 建立的內容

此元範本會生成完整的上下文工程範本包，包含：

### 生成的範本結構
```
use-cases/{技術名稱}/
├── CLAUDE.md                          # 技術特定的全局規則
├── .claude/commands/
│   ├── generate-{tech}-prp.md        # 領域 PRP 生成
│   └── execute-{tech}-prp.md         # 領域 PRP 執行
├── PRPs/
│   ├── templates/
│   │   └── prp_{tech}_base.md        # 技術特定的基礎 PRP
│   ├── ai_docs/                      # 領域文件
│   └── INITIAL.md                    # 功能請求範例
├── examples/                         # 技術特定的範例
└── README.md                         # 使用指南
```

### 範本特點

**技術專業化：**
- 框架特定的全局規則和模式。
- 適合技術的驗證迴圈。
- 領域特定的研究方法論。
- 框架專門的文件參考。

**網頁研究整合：**
- 為技術研究提供廣泛的網頁搜尋需求。
- 官方文件的收集與分析。
- 真實世界模式的識別與提取。
- 最佳實踐和陷阱文件。

**上下文工程調整：**
- 為特定技術調整的 PRP 框架。
- 適合領域的成功準則。
- 技術特定的實作藍圖。
- 框架專門的驗證關卡。

## 🔍 研究驅動的方法

此元範本強調將**廣泛的網頁研究**作為建立高品質範本的基礎：

1. **技術深挖** —— 對官方文件、模式和最佳實踐進行全面研究。
2. **模式提取** —— 識別真實世界的實作模式。
3. **上下文整合** —— 為該技術調整上下文工程原則。
4. **驗證設計** —— 建立適合技術的測試和驗證迴圈。

## 📋 使用流程

### 1. 定義需求 (PRPs/INITIAL.md)

請對以下內容保持極高的具體性：
- **目標技術/框架**
- **要支援的核心功能**
- **要包含的範例**
- **要研究的文件**
- **開發模式**
- **安全性考量**
- **常見陷阱**
- **驗證需求**

### 2. 生成範本 PRP

```bash
/generate-template-prp PRPs/INITIAL.md
```

這將會：
- 對您指定的技術進行廣泛的網頁研究。
- 分析官方文件和最佳實踐。
- 建立全面的實作藍圖。
- 設計技術特定的驗證迴圈。

### 3. 執行範本生成

```bash
/execute-template-prp PRPs/template-{技術名稱}.md
```

這將會：
- 建立完整的範本包目錄結構。
- 生成帶有全局規則的技術特定 `CLAUDE.md`。
- 為該技術建立專門的 PRP 命令。
- 開發領域特定的基礎 PRP 範本。
- 包含可運行的範例和全面的說明文件。
