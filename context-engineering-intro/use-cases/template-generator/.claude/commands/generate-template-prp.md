# 生成範本 PRP (Generate Template PRP)

## 功能檔案：$ARGUMENTS

根據 `INITIAL.md` 檔案中的詳細需求，為建立特定技術領域的上下文工程範本生成完整的 PRP。這遵循標準的 PRP 框架工作流：INITIAL.md → generate-template-prp → execute-template-prp。

**重要：網頁搜尋和文件研究是您最好的朋友。請在整個過程中廣泛使用。**

## 研究流程 (Research Process)

1. **閱讀並理解需求**
   - 徹底閱讀指定的 `INITIAL.md` 檔案。
   - 理解目標技術和特定的範本需求。
   - 記錄提到的任何特定功能、範例或說明文件。
   - 確定所需範本的範圍和複雜性。

2. **廣泛的網頁研究 (重要)**
   - **廣泛搜尋目標技術** —— 這是必不可少的。
   - 學習官方說明文件、API 和入門指南。
   - 研究最佳實踐和常見的架構模式。
   - 尋找真實世界的實作範例和教學。
   - 識別常見的陷阱 (Gotchas)、缺陷和邊緣情況。
   - 尋找既有的專案結構慣例。

3. **技術模式分析**
   - 檢視透過網頁研究找到的成功實作。
   - 識別專案結構和檔案組織模式。
   - 提取可重用的程式碼模式和配置範本。
   - 記錄框架特定的開發工作流。
   - 記錄測試框架和驗證方法。

4. **上下文工程調整**
   - 將發現的技術模式對應到上下文工程原則。
   - 規劃如何為此特定技術調整 PRP 框架。
   - 設計領域特定的驗證需求。
   - 規劃範本包的結構和組件。

## PRP 生成 (PRP Generation)

使用 `PRPs/templates/prp_template_base.md` 作為基礎：

### 網頁研究中應包含的關鍵上下文

**技術文件 (來自網頁搜尋)**：
- 官方框架文件 URL 及特定章節。
- 入門指南與教學。
- API 參考和最佳實踐指南。
- 社群資源和範例儲存庫。

**實作模式 (來自研究)**：
- 框架特定的專案結構與慣例。
- 配置管理方法。
- 開發工作流模式。
- 測試與驗證方法。

**真實世界範例**：
- 在網上找到的成功實作連結。
- 程式碼片段和配置範例。
- 常見的整合模式。
- 部署與設定流程。

### 實作藍圖 (Implementation Blueprint)

根據網頁研究結果：
- **技術分析**：記錄框架特徵與模式。
- **範本結構**：規劃完整的範本包組件。
- **專業化策略**：如何為此技術調整上下文工程。
- **驗證設計**：適合技術的測試與驗證迴圈。

### 驗證關卡 (必須是可執行的)

```bash
# 範本結構驗證
ls -la use-cases/{技術名稱}/
find use-cases/{技術名稱}/ -name "*.md" | wc -l  # 應具備所有必需檔案

# 範本內容驗證
grep -r "TODO\|PLACEHOLDER" use-cases/{技術名稱}/  # 應為空
grep -r "WEBSEARCH_NEEDED" use-cases/{技術名稱}/  # 應為空

# 範本功能測試
cd use-cases/{技術名稱}
/generate-{技術名稱}-prp INITIAL.md  # 測試領域特定 PRP 生成
```

*** 重要：在編寫 PRP 之前進行廣泛的網頁研究 ***
*** 廣泛使用 WebSearch 工具以深度理解技術 ***

## 輸出 (Output)

儲存為： `PRPs/template-{技術名稱}.md`
