# 執行 MCP 伺服器 PRP (Execute MCP Server PRP)

執行一個全面的產品需求提示 (PRP)，用於構建具備身分驗證、資料庫整合和 Cloudflare Workers 部署功能的模型上下文協定 (MCP) 伺服器。

要執行的 PRP： $ARGUMENTS

## 目的

遵循本程式碼庫中經過驗證的模式，執行具備全面驗證、測試和部署驗證的 MCP 伺服器 PRP。

## 執行流程

1. **載入與分析 PRP**
   - 完整閱讀指定的 PRP 檔案。
   - 理解所有上下文、需求和驗證標準。
   - 使用 `TodoWrite` 工具建立全面的待辦事項列表。
   - 識別所有依賴項和整合點。

2. **上下文收集與研究**
   - 使用任務代理人研究現有的 MCP 伺服器模式。
   - 研究身分驗證流程和資料庫整合模式。
   - 研究 Cloudflare Workers 部署和環境設定。
   - 收集所有必要的文件和程式碼範例。

3. **實作階段**
   - 按正確順序執行所有實作任務。
   - 遵循現有程式碼庫中的 TypeScript 模式。
   - 實作 MCP 工具、資源和身分驗證流程。
   - 新增全面的錯誤處理和日誌記錄。

## 注意事項

- 使用 `TodoWrite` 工具進行全面的任務管理。
- 遵循來自經過驗證的程式碼庫實作的所有模式。
- 包含全面的錯誤處理與恢復機制。
- 針對 Claude Code 的驗證迴圈進行優化。
- 生產就緒，具備監控和日誌記錄功能。
- 相容於 MCP 檢查器 (Inspector) 和 Claude Desktop。
