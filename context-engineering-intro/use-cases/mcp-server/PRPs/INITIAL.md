## FEATURE (功能)：

我們想要使用此儲存庫的範本建立一個 MCP 伺服器。

該 MCP 伺服器的目標是建立一個簡單版本的 Taskmaster MCP，但我們解析的是 PRP (產品需求提示) 而非 PRD。

額外功能：

- 使用 Anthropic 驅動的 LLM PRP 資訊提取。
- 對資料庫中的任務、文件、標籤等進行 CRUD (增刪改查) 操作。

我們需要用於解析 PRP 的工具。此工具應接收已填寫的 PRP，並使用 Anthropic 將任務提取出來並儲存到資料庫中，同時包含來自 PRP 的周邊文件，如目標 (Goals)、內容與原因 (What/Why)、目標使用者等。

我們需要：

- 能夠對任務、文件、標籤等執行 CRUD 操作。
- 一個任務獲取工具，用於從資料庫獲取任務。
- 能夠列出所有任務。
- 能夠向任務新增資訊。
- 能夠從資料庫獲取額外文件。
- 能夠修改額外文件。
- 需要更新資料庫資料表以匹配我們的新資料模型。

## EXAMPLES & DOCUMENTATION (範例與文件)：

所有範例已在 `prp_mcp_base.md` 中引用 —— 請根據需要進行任何額外研究。

## OTHER CONSIDERATIONS (其他考量)：

- 不要使用複雜的正則表達式 (Regex) 或複雜的解析模式，我們使用 LLM 來解析 PRP。
- Anthropic 的模型和 API 金鑰都需要作為環境變數 —— 這些已在 `.dev.vars.example` 中設定。
- 非常重要的一點是：每個檔案建立一個任務，以保持關注點分離。
