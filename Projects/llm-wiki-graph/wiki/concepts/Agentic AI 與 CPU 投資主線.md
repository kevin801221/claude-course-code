# Agentic AI 與 CPU 投資主線

這個概念描述的是：隨著 Agentic AI 工作流變複雜，CPU 在任務調度、系統控制與整體運算架構中的重要性上升，因此 CPU 相關公司可能被市場重新定價。

## 定義

過去 AI 投資敘事常偏向 GPU，但這份來源認為，當 AI 任務從單點模型推論走向多步驟協作流程時，CPU 不再只是配角，而是更核心的基礎層。

## 這份來源怎麼談

[[財經 Podcast EP.XXX]] 提到幾個支撐這條主線的訊號：

- [[AMD]] 持續擴大 x86 市場存在感
- [[Intel]] 管理層承認低估 CPU 需求，反映需求可能比預期更強
- [[NVIDIA]] 推出整合 CPU 的平台，代表 GPU 龍頭也在強化 CPU 佈局
- [[Arm]] 在伺服器市場份額提升
- 台股可關注與 CPU Socket 高度相關的 [[技嘉]]

## 風險與限制

- 上游產能瓶頸可能限制這條主線的兌現速度
- 來源同時指出 [[台積電]] 與 [[聯電]] 代表的供應鏈限制可能影響 CPU 與 GPU 的產能分配
- 估值未必便宜，若只靠敘事推升，後續仍需觀察實際出貨與訂單
