## 💡 三大重點（附 [時間戳]）

- **Cowork vs Chat 的根本差別：直接編輯本機原檔，不是吐一個新檔** [04:46 業務痛點 → 05:42 看實演下指令]
  示範用 Q2 業績報表（有合併儲存格、藍色標題、自動加總公式），請它新增「樞紐分析」工作表＋長條圖，**原本三個分頁完全不動**。對照組把同一指令丟 Chat，只會生一份全新 Excel，格式跑掉。一句話：「Chat 的世界只有上傳跟下載，Cowork 的世界是直接編輯」[06:52]。

- **Live artifacts：會自己長大的累積式儀表板** [07:14 → 08:15 看趨勢線長出來]
  建一個「帳單追蹤」資料夾當數據投放區，丟 PDF 進去，叫 Cowork 做含圓餅圖／趨勢長條圖／明細表的儀表板，存進 Live artifacts 分頁。之後每月把新帳單丟進去說「更新儀表板」就疊加，從「一次性分析」升級成「持續追蹤」，累積夠多還能問深度問題（哪類花費漲最快、是前三個月幾倍）[08:33]。

- **Skill：把重複 SOP 打包，一句話跑完** [09:04 → 10:12 看一鍵執行示範]
  把第一、二章的流程寫成純文字 SOP 打包成 Skill。之後只說「跑每週業績報表」，Cowork 自動跑完 6 步：① 識別 Skill 觸發 → ② 抓資料夾新檔 → ③ 開檔新增本週分頁 → ④ 算總額＋前 5 名長條圖 → ⑤ 備份到桌面 → ⑥ 回報 [10:28–10:42]。金句：「你不是在『用 AI』，是在『養一個專屬助理』」[11:02]。

## 📚 提到的工具 / 概念

- **Cowork 左欄六大功能** [00:43–02:13]：New task（多步驟自動跑）[00:51]、Projects（任務/檔案/context 分專案管理）[01:09]、Scheduled（每天/週/月排程自動執行）[01:22]、Live artifacts（持續互動的 HTML 頁面）[01:38]、Dispatch（手機派任務給家裡桌機）[01:55]、Customize（設預設行為偏好）[02:06]
- **Skill 是 Anthropic 官方概念**：免費版內建 `pptx skill` / `docx skill`，付費版才可自建＋上傳；建立途徑兩條 — Customize 裡新增、或開 New Chat 跟 Claude 討論請它幫你建 [09:21 / 09:57]
- **在 VPS 上跑 Claude Code**（業配 Hostinger 段落 [02:19–04:45]）：Terminal 右鍵貼上（不能 Ctrl/Cmd+V）、curl 一行裝好、預設模型 **Sonnet 4.6**，且和本機 Claude 共用額度 [04:18–04:41]
- 安全提醒：Cowork 真的會動你硬碟，動檔案前**先另存新檔/備份** [05:27 / 06:03]
- 留待下集：Scheduled 的詳細設定（搭配 Live artifacts 每月 1 號自動跑）[08:53]

## 🤔 我的一句話觀察

這集把 Cowork 三功能講成一條「狀態保存的升級階梯」——**單次編輯（直接改原檔）→ 累積狀態（Live artifacts 儀表板）→ 流程固化（Skill 一句話觸發）**，剛好對應教學包裡 Skill 那一章想傳達的「重複的事就打包成 SOP」；不過影片把「自建 Skill」框成付費版專利，其實在 Claude Code CLI 用 `.claude/skills/` 本來就免費能做（就像這個 `/youtube-notes` 本身），只是對 Cowork 桌面 app 的受眾這樣講比較直觀。
