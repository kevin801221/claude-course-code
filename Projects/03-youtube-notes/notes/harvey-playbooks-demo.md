## 🎬 Harvey In Practice: Build and Run Playbooks — 全長 2 分 / 讀完 3 分

> 來源：https://www.youtube.com/watch?v=_iT_adwg_Os
> 性質：Harvey（法律 AI）官方產品 demo，主講人 Millie（前 Whiting & Case associate）。

### 💡 三大重點（附 [時間戳]）

- **Playbook 從「靜態文件」變「結構化規則集」** [0:38]
  Manager 上傳內部 playbook（任何格式皆可），Harvey 自動拆成結構化規則：每個條款的**標準立場（standard）/ 退讓條款（fallback）、不可接受的偏離（unacceptable deviations）、內部談判指引** [0:46]。在 settings 分頁管理，並有 build / run / manage 三層權限分級 [0:28]，review、finalize 後再分享給特定人或整個 workspace [0:54]。

- **在 Word Add-in 裡實際「跑」起來，自動三色分類** [1:01]
  把 playbook 對一份草約 run，Harvey 逐條把條款分類成 **acceptable / needs review / not acceptable** [1:08]。點進任一被標記條款，可看到 Harvey 的判斷理由（reasoning）、對應的原始規則、以及相關內部指引 [1:16]——不是黑箱打勾，是把依據攤開。

- **一鍵紅線改稿 + 匯出摘要** [1:22]
  Harvey 直接建議 red lines 把條款改向標準或 fallback 立場，一鍵套用 markup [1:26]；可加註解說明修訂以加速談判回合 [1:28]；也能**一鍵套用全部標準立場** [1:38]。完成後匯出 summary 給 manager 或同事 [1:41]。

### 📚 提到的工具 / 概念

- **Playbook** — 律所內部審約準則（NDA、商業合約的標準/fallback 立場與談判指引）
- **權限分級** — build / run / manage 三種角色 [0:28]
- **Word Add-in** — Harvey 嵌進 Word 的審約工作流，「playbook 活起來的地方」 [1:04]
- **三色分類** — acceptable / needs review / not acceptable [1:12]
- **Red lining / standard·fallback positions** — 一鍵改紅線對齊預設立場 [1:22]
- **匯出 summary** — 審約結果摘要分享 [1:41]

### 🤔 我的一句話觀察

這支是行銷向 demo，開場刻意用「我曾是 Whiting & Case 律師」建立同行信任——真正的賣點是把律所最值錢的隱性資產（資深律師腦中的談判底線與 fallback 邏輯）**標準化、可規模化複用**，讓初級律師也能跑出一致品質。但 demo 全程沒碰最關鍵的兩個現實問題：Harvey 分類錯誤（把 not acceptable 判成 acceptable）時的責任歸屬，以及律師仍需逐條覆核的真實成本——「一鍵套用全部標準立場」聽起來爽，但敢這樣用的場景恐怕只限低風險的標準 NDA。
