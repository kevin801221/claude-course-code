# CR-01 增量契約（v1 凍結之後才發）

以 v1 同一資料庫啟動新版本，不重設資料。接口增補：

- 新送的外部申請狀態為 pending_approval，queue=null；只有核准時才能取得當下座位或新的候補序號。
- `POST /api/sessions/:sid/review/:uid`，僅 HR，JSON `{"decision":"approve"}` 或 `{"decision":"reject"}`。回更新的報名記錄；相同決定重送冪等，反向決定、核准已取消的申請回 409。已拒絕者可重新申請。截止後不能新增，但可處理已送的 pending。
- 瀏覽器：詳情顯示「我的狀態：待審核」；HR 審核列提供「核准」「拒絕」按鈕；學員回「我的報名」看到結果。
- 共用驗收環境 WORKSHOP_PHASE=v1 或 cr（未設定＝v1）用同一份資料庫檢查狀態過渡。若兩版為分開程式，提供相容啟動方式或封裝兩份版本供評分者驗證。
