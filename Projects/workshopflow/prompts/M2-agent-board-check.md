# M2-agent-board-check

以下貼入互動式 Claude Code：

請實際平行啟動兩位普通 subagents，唯讀檢查剛建立的 agent-board Mod，不要只在主對話扮演兩個角色。若此 session 的 Agent Teams 設定把新代理轉成 teammate，請先回報並讓我在普通 subagents 模式重開，避免測錯模式。
A「結構檢查員」：檢查 plugin manifest、hook 設定與實作入口是否一致，說明各檔用途與實際引用關係，回報疑點與檔案位置。
B「畫面檢查員」：檢查 /agent-board、Pane、$.agent.list()、空狀態與重新整理的程式路徑；說明按下按鈕是否真的重讀並重畫。若沒有終端 UI 操作能力，明確標為程式碼檢查，不要聲稱已點擊或看見畫面。
共同限制：只讀，不修改檔案、不安裝依賴、不執行破壞性操作；不要新增無意義等待來製造忙碌狀態。
主代理等兩份回報後，整理「通過、缺陷、未驗證」清單與證據。不得把靜態檢查寫成實機通過。
我會在這段期間開啟 /agent-board，按重新整理，觀察兩位代理從執行中到完成；如果工作太快，請如實說明清單可能已完成，不得捏造過渡畫面。
