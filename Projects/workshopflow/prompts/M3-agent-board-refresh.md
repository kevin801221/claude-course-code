# M3-agent-board-refresh

以下貼入互動式 Claude Code：

請在既有 agent-board Mod 上加入自動更新，保留原本手動重新整理功能。
先讀當前實作，核對本機 Mods 型別與官方計時、UI 重畫、Pane 開關及卸載事件 API；不要猜 setInterval 或事件名稱在此 runtime 可用。
需求：
1. Pane 開啟期間，每 1 秒重新讀取 $.agent.list() 並重畫；禁止請求重疊，前一次尚未結束就不要另起一次。
2. Pane 關閉後停止定時更新；重新開啟時恢復。重複開啟、熱重載與卸載要清理，不能累積多個計時器。
3. 保留手動重新整理；顯示最後一次成功更新時間。時間請使用本機支援的 Mods API。
4. 讀取失敗時保留最後一份成功資料，標示「更新失敗／資料過期」，不能把錯誤畫成沒有代理。
5. 不呼叫模型、不啟動代理、不修改正在執行的任務、不估算沒有來源的完成率或費用。
完成後執行可用的 plugin validate 與必要的計時器生命週期測試。再說明如何用 M2 兩位唯讀子代理確認：不按刷新也會更新、關閉後停止、重開恢復、重載不重複。
回報實際改動、驗證證據和未測項目；若你不能操作終端 Pane，請把 UI 驗證留給我，不要捏造通過。
