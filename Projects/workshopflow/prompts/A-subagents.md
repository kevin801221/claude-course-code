現在採用 A：普通 Subagents 完成前一則 P2 的 WorkshopFlow 任務。
先核對本 session 未將新代理轉為 Agent Teams teammate；若目前設定是 Teams，停下說明如何切回普通模式，不要冒充 A。
你是主代理與資深顧問，負責契約、排程、跨模組決策及整合。最多建立 3 位專家 subagents：前端、後端／資料、QA。先整理共同 API、狀態機與檔案責任，再平行交辦清楚、有交付條件的任務。QA 可先根據 PRD 設計測試，取得實作後再驗證。
本組實驗協定：專家將結果、風險與契約疑問回報主代理，由主代理決定下一步與跨模組修改；這是本次控制方式，不是宣稱 subagents 技術上完全不能互傳。
每位回報包含：完成項目、改動檔案、契約版本、實際測試命令與結果、未決問題。主代理核對並整合，執行共同驗收，將失敗分派給負責者；遵守 P2 的時間和最多 2 輪修復限制。
不要用主代理一人寫完後假裝曾分工。保留實際代理與任務紀錄，記下主代理做了哪些整合決策、多少次等待或重工。完成 v1 保存版本與證據，等待 CR-01。
